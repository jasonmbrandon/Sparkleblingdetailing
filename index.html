How booking works

                            
    
                                
  1. The booking form asks the Sparkle – Booking API for prices and every open time on the chosen day, then books the slot the customer picks.
    2. 
                                
  2. The Sparkle – Booking Engine works out open times from your Settings tab and Google Calendar, re-checks the slot, creates the Calendar event and logs it in the Leads sheet.
    3. 
                                
  3. The customer and owner get a confirmation email, and Sparkle – Daily Reminders emails the customer the day before.
    4. 
                                
  4. The chat agent answers questions and quotes, then shows a Pick a time button that opens the form pre-filled. It never books on its own.
    5. 
                                
  5. If n8n is down, the form switches to request mode and the chat uses the offline assistant. Requests go to Sparkle – Lead Intake for you to confirm by text.
    6. 
                            

                            

                                
Chat request: { sessionId, message, testMode, context }

                                
Chat reply: { reply, openBooking|null, handoff }

                                
Booking API: { action: public_settings | get_quote | find_slots | book, … }
